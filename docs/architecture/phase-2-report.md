# Phase 2 — Graph Editor: отчёт

## Что сделано

**Модель графа (`MindMesh.Graph`, без зависимости от UI).** Узлы, порты, соединения, `NodeGraph` с событиями изменений,
Guid-v7 идентификаторы. Определение (`INodeDefinition`), состояние графа и состояние редактора (позиции, выделение, zoom)
разделены. Типизированные порты: Any, String, Number, Integer, Decimal, Boolean, Object, Array, Json, DateTime, Binary,
Execution, Event, AIContext; правила совместимости в `PortCompatibility`. Проверка соединения (`CheckConnection`)
возвращает причину отказа: TypeMismatch, WrongDirection, SameNode, UnknownPort, Duplicate, Cycle; соединение в уже занятый
одиночный вход заменяет старое. Undo/redo (`GraphDocument`, составные команды, склейка правок одного параметра),
copy/paste/duplicate (`GraphFragment`: новые id, секреты не копируются), валидация узлов.

**Расширяемость.** `MindMesh.Plugins.Abstractions` — только контракты (реестр видов проектов, режимы, категории, определения нод).
Лицензирование и монетизация точкой расширения **не являются**. `MindMesh.Nodes` — встроенные определения всех нод из спецификации
(только определения: исполнители появятся в Phase 4). Реестр `ExtensionCatalog` собирает расширения и сообщает о конфликтах.

**Холст.** Гибридный: контролы Avalonia с трансформацией pan/zoom + `DrawingContext` для сетки и соединений. Pan, zoom к курсору,
перетаскивание узлов с привязкой к сетке, выделение кликом/рамкой/Ctrl+A, создание соединений перетаскиванием с подсветкой
совместимых портов, переподключение, быстрое добавление ноды (Space / двойной клик / контекстное меню), culling невидимых узлов,
миникарта, плавающая панель инструментов. Состояния узла: Default, Selected, Running, Completed, Failed, Disabled, Warning.
Вся геометрия и hit-testing — в мировых координатах внутри view-модели, поэтому проверяются тестами без UI.

**Инспектор.** Форма строится по схеме параметров: Text, Number, Boolean, Select, MultiSelect, Code, Expression, JSON (AvaloniaEdit),
Secret, File Picker, Dynamic Fields. Ошибки показываются под полем; условная видимость (`VisibleWhen`); набор текста — один шаг undo.
Секреты хранятся в `ISecretStore`, в графе только ссылка `secret:<guid>`.

**Библиотека нод.** Разделы по категориям текущего режима, плитки 2 в ряд с цветными иконками, поиск (имя, описание, ключевые слова,
оба языка), добавление двойным кликом или перетаскиванием на холст.

**Оформление.** По референсу: светлая тема по умолчанию (белые карточки, точечная сетка), тёмная — переключатель в настройках.

## Тесты

| Проект | Что проверяет |
|---|---|
| `MindMesh.Graph.Tests` | совместимость портов, правила соединений, undo/redo, copy/paste, параметры, валидация |
| `MindMesh.Nodes.Tests` | целостность встроенных нод (id, порты, параметры, категории), каталог расширений |
| `MindMesh.Presentation.Tests` | холст (drag, выделение, соединения, culling, zoom), инспектор, библиотека, настройки темы, полнота ресурсов |
| `MindMesh.UI.Tests` | все ключи иконок существуют в `IconCatalog` |

## Не сделано / ограничения

- **Ничего не собиралось и не запускалось**: в среде нет .NET SDK. Проверка только статическая. Ошибки компиляции и упавшие тесты
  нужно прислать.
- Версия AvaloniaEdit (12.0.0) и подключение её стиля не сверялись с реальным пакетом.
- Подписи портов и параметров встроенных нод только на английском (названия, описания и категории нод — на en/ru).
- Нет избранного и «недавних» в библиотеке; нет групп, комментариев и auto layout (отложено по договорённости).
- Секреты живут в памяти процесса и не сохраняются на диск (хранилище появится вместе с проектами, Phase 3).
- Validate / Run / Debug отключены: нет активного workflow и рантайма.
- Подсказок у портов на холсте нет (слой узлов не участвует в hit-testing), автопрокрутки у края при перетаскивании нет.
- Ранее сохранённая тёмная тема остаётся тёмной; светлая — только для новых настроек.
- Клиентские проверки лицензий обходимы по природе клиентского кода; поэтому лицензирование не вынесено в плагины.
